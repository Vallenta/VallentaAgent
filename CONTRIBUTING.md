# Contributing

This is a proprietary project — the source code is not open for external contributions.

However, we welcome and appreciate:
- Bug reports and issue submissions
- Feature requests and suggestions
- General feedback and tips

Please use the [Vallenta Studio issue tracker](https://github.com/Vallenta/Studio/issues) to
share your input. It covers the agent as well as the extension, so everything about Linux
debugging stays in one place. Thank you!
